# 과학구리

전남과학고 학생을 위한 정보 제공 웹사이트입니다. 과제, 시간표, 학사일정, 급식과 게시판 등의 정보를 한곳에서 확인할 수 있습니다.

웹사이트: <https://jshs-us.github.io/jshs/>

## 주요 기능

- 과제 및 최근 과제 미리보기
- 시간표 및 오늘의 시간표 미리보기
- 학사일정 및 월간 일정 미리보기
- 급식 메뉴와 원산지 정보
- 로그인 기반 게시판
- 벌금 정보와 관리자 안내
- 모바일 화면 및 PWA 지원
- Capacitor 네이티브 앱에서 실행할 때 외부 링크, 뒤로가기, 네트워크 상태 등을 처리하는 브리지

## 페이지

| 파일 | 내용 |
| --- | --- |
| `index.html` | 홈 및 주요 정보 미리보기 |
| `homework.html` | 과제 |
| `timetable.html` | 시간표 |
| `calendar.html` | 학사일정 |
| `meal.html` | 급식 |
| `board.html` | 게시판 |
| `fine.html` | 벌금 관리 |
| `mypage.html` | 마이페이지 |
| `admin.html` | 관리자 정보 |


그다음 브라우저에서 <http://localhost:8000>을 엽니다. 일부 브라우저 기능은 `file://`로 직접 여는 대신 로컬 서버에서 확인해야 합니다.

## 설정 및 연동

- `config.js`의 `SCRIPT_URL`은 로그인, 게시판 등에서 사용하는 Google Apps Script 웹 앱 주소입니다. 다른 환경에 배포할 때는 해당 환경의 주소로 설정하세요.
- 과제, 시간표, 학사일정, 급식 데이터는 각 페이지에서 참조하는 Google 스프레드시트와 연동됩니다.
- 게시판 이미지 업로드 및 알림 등 일부 기능은 외부 서비스와 서버 측 설정에 의존합니다.
- 웹 브라우저에서는 `native-bridge.js`가 네이티브 전용 동작을 건너뜁니다. 네이티브 앱 빌드 설정과 Capacitor 프로젝트는 이 저장소에 포함되어 있지 않습니다.

## 배포

사이트는 GitHub Pages의 프로젝트 사이트로 제공됩니다. 정적 파일의 변경 사항을 저장소의 기본 배포 브랜치에 반영하면 Pages 설정에 따라 배포됩니다. HTML 파일 간 상대 경로와 외부 연동 설정이 배포 환경에서도 유효한지 확인하세요.
